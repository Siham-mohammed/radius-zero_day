# Linux Terminal Navigation & Environment Exploration

This directory contains basic linux commands to navigate linux filesystem ,to create, identify directory and files.

## Commands Practised

cd - to change directories using absolute or relative path

ls - to list all files and directories in the current folder by adding -l we can see more detail about the list and -a includes hidden files too.

whoami - to check who is currently using (the account )
 pwd - to check current directory
 mkdir - to create directories and touch to create files
